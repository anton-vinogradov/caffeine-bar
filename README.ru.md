# caffeine-bar

Переключатель `caffeinate` в строке меню macOS. Он показывает и чужие
`caffeinate`, которые не дают маку уснуть: например, те, что скрипты и
ИИ-агенты запустили в фоне.

## Зачем

Скрипты и ИИ-агенты часто запускают `caffeinate -dimsu -t 7200 &`, чтобы мак
не уснул посреди долгой работы. Другие приложения для строки меню с такими
процессами обходятся плохо:

- KeepingYouAwake, Amphetamine, Caffeine и похожие показывают только своё
  состояние. Их иконка говорит «выключено», хотя мак держат пять фоновых
  `caffeinate`.
- Расширение Coffee для Raycast делает наоборот: считает своим любой
  `caffeinate`, а при включении и выключении вызывает `killall caffeinate`.
  Так оно останавливает и `caffeinate` ваших агентов.

caffeine-bar раз в 2 секунды читает те же данные, что показывает
`pmset -g assertions`, и выводит их целиком. Останавливает оно только то, что
вы сами попросили остановить.

## Как пользоваться

- **Клик** по иконке включает и выключает. Включение бессрочное.
- **Правый клик** (или клик с Control или Option) открывает меню:
  - **Включить на…**: от 30 минут до 8 часов.
  - **Экран может гаснуть**: система не спит, но экран гаснет по расписанию.
  - **caffeinate сейчас**: все процессы `caffeinate` — кто запустил, из какой
    папки и сколько осталось, например
    `Claude Code (my-project) · ещё 1 ч 20 мин`. Если приложение или сессия,
    которые его запустили, уже закрыты, строка так и скажет: такой
    `caffeinate` остался без хозяина, его можно смело останавливать. В
    подменю — флаги, время запуска и кнопка остановки.
  - **Ещё не дают уснуть**: другие приложения, которые держат мак прямо
    сейчас, например десктопный Claude.
  - **Запускать при входе**. При первом запуске приложение один раз спросит
    об этом само.
  - **Проверить обновления**.
- **Наведите** курсор на иконку, чтобы увидеть краткую сводку.

На русской системе меню русское, на любой другой — английское.

## Как устроено

Включение запускает `/usr/bin/caffeinate -dims -w <pid приложения>` (или
`-ims`, если экрану можно гаснуть) и добавляет `-t <секунды>` для таймера.
Благодаря `-w` `caffeinate` завершается вместе с приложением, даже после сбоя
или `kill -9`.

Список берётся из `IOPMCopyAssertionsByProcess`, тех же данных, что печатает
`pmset -g assertions`. Процесс считается держащим мак, если он запрещает сон
системы или экрана по бездействию. `caffeinate -s` засчитывается только от
сети: от батареи macOS его не учитывает.

«Кто запустил» — это приложение, которое macOS считает ответственным за
процесс. Оно сохраняется и после `nohup … &`, когда промежуточная оболочка
завершилась и родителем стал launchd: для ИИ-агента это приложение агента, для
команды в терминале — терминал. Когда это приложение закрывается, macOS его
забывает, и процесс усыновляет launchd. Настоящую службу launchd запустил сам
launchd, и она возглавляет свою группу процессов. Оставшийся без хозяина
процесс не проходит одну из этих проверок, по этому меню и понимает, что
запустивший уже закрыт. Папка — рабочий каталог процесса.

## Обновления

Раз в сутки приложение спрашивает у GitHub API последний релиз этого
репозитория. Если он новее, в меню появляется **Обновить до X…**. Приложение
скачивает zip, проверяет его подпись Ed25519 открытым ключом, встроенным в
приложение, заменяет себя и перезапускается. Если приложение не давало маку
спать, после перезапуска оно продолжит. Zip без верной подписи не
устанавливается никогда. Запрос к GitHub — единственное, что приложение
отправляет в сеть.

В версии 1.0.0 обновлений ещё нет: 1.1.0 или новее один раз поставьте руками.

## Ограничения

Это ограничения macOS, а не приложения:

- Запрещается только сон **по бездействию**. Если закрыть крышку MacBook, он
  уснёт. Исключение — режим закрытой крышки: питание от сети плюс внешний
  монитор.
- Таймеры на время сна останавливаются, так же как `caffeinate -t`. Таймер на
  2 часа — это 2 часа бодрствования.
- Если строка меню заполнена, macOS прячет новые значки под вырезом экрана.
  Освободите место: перетащите значки с зажатой ⌘ или скройте лишние в
  Системных настройках → Строка меню. Если открыть приложение ещё раз через
  Spotlight или Finder, оно покажет окно с состоянием и кнопкой включения.

## Установка

Нужна macOS 15 или новее. Приложение работает на Apple Silicon и Intel.

### Скачать готовое

1. Скачайте `CaffeineBar-<версия>.zip` из
   [последнего релиза](https://github.com/anton-vinogradov/caffeine-bar/releases/latest)
   и распакуйте.
2. Перенесите `CaffeineBar.app` в `~/Applications` или `/Applications`.
3. Приложение подписано ad hoc, без сертификата разработчика Apple, поэтому
   первый запуск macOS заблокирует. Снимите флаг карантина один раз:

   ```bash
   xattr -dr com.apple.quarantine ~/Applications/CaffeineBar.app
   ```

   Или попробуйте открыть приложение, затем зайдите в Системные
   настройки → Конфиденциальность и безопасность и нажмите **Все равно
   открыть**.

### Собрать самому

Дополнительно нужны Xcode Command Line Tools (`xcode-select --install`).

```bash
git clone https://github.com/anton-vinogradov/caffeine-bar.git
cd caffeine-bar
./build.sh install
```

`build.sh` собирает Swift-файлы через `swiftc` сразу для Apple Silicon и
Intel, подписывает приложение ad hoc, копирует его в `~/Applications` и
запускает. У локальной сборки нет флага карантина, поэтому Gatekeeper её
пропускает. Без `install` скрипт только собирает `build/CaffeineBar.app`.
`./build.sh zip` ещё и упаковывает его в zip для релиза.

Чтобы приложение запускалось при входе, выберите в меню **Запускать при
входе**.

### Выпуск релиза

Ключ подписи лежит в Связке ключей входа на маке того, кто выпускает релизы.
Читать его не доверено ни одному приложению, поэтому при каждой подписи zip
macOS спрашивает пароль Связки ключей. Нажимайте **Разрешить**, но никогда
**Разрешать всегда**: иначе ключ сможет прочитать любой `swift`-скрипт.
Создайте ключ один раз и вставьте напечатанный открытый ключ в
`Updater.swift`:

```bash
swift -suppress-warnings scripts/update-key.swift new
```

Сохраните резервную копию ключа: `export` печатает его для менеджера паролей,
`import` читает обратно на другом маке. Без ключа установленные копии не
смогут обновиться сами, и следующую версию придётся ставить руками.

Для каждого релиза поднимите `VERSION` в `build.sh`, затем:

```bash
./build.sh zip
gh release create v1.2.3 build/CaffeineBar-1.2.3.zip build/CaffeineBar-1.2.3.zip.sig
```

## Совет для скриптов и агентов

Передайте `caffeinate` pid процесса, который живёт столько же, сколько работа.
Тогда `caffeinate` завершится вместе с ней и не будет ждать весь `-t`:

```bash
caffeinate -dimsu -t 7200 -w $PPID &
```

`$PPID` — это процесс, который запустил текущую оболочку. У shell-инструмента
ИИ-агента это обычно сам агент.
