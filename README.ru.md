# caffeine-bar

Переключатель `caffeinate` в строке меню macOS. Он показывает и чужие
`caffeinate`, которые не дают маку уснуть: например, те, что скрипты и
ИИ-агенты запустили в фоне.

## Зачем

Скрипты и ИИ-агенты часто запускают `caffeinate -dimsu -t 7200 &`, чтобы мак
не уснул посреди долгой работы. Другие приложения для строки меню с такими
процессами обходятся плохо:

- KeepingYouAwake, Amphetamine, Caffeine и похожие показывают только своё
  состояние. Их иконка говорит «выключено», хотя мак держат пять фоновых
  `caffeinate`.
- Расширение Coffee для Raycast делает наоборот: считает своим любой
  `caffeinate`, а при включении и выключении вызывает `killall caffeinate`.
  Так оно останавливает и `caffeinate` ваших агентов.

caffeine-bar раз в 2 секунды читает те же данные, что показывает
`pmset -g assertions`, и выводит их целиком. Останавливает оно только то, что
вы сами попросили остановить.

## Как пользоваться

- **Клик** по иконке включает и выключает. Включение бессрочное.
- **Правый клик** (или клик с Control или Option) открывает меню:
  - **Включить на…**: от 30 минут до 8 часов.
  - **Экран может гаснуть**: система не спит, но экран гаснет по расписанию.
  - **caffeinate сейчас**: все процессы `caffeinate` с флагами и оставшимся
    временем. Свой помечен «моё». Можно остановить любой или все сразу.
  - **Ещё не дают уснуть**: другие приложения, которые держат мак прямо
    сейчас, например десктопный Claude.
  - **Запускать при входе**.
- **Наведите** курсор на иконку, чтобы увидеть краткую сводку.

На русской системе меню русское, на любой другой — английское.

## Как устроено

Включение запускает `/usr/bin/caffeinate -dims -w <pid приложения>` (или
`-ims`, если экрану можно гаснуть) и добавляет `-t <секунды>` для таймера.
Благодаря `-w` `caffeinate` завершается вместе с приложением, даже после сбоя
или `kill -9`.

Список берётся из `IOPMCopyAssertionsByProcess`, тех же данных, что печатает
`pmset -g assertions`. Процесс считается держащим мак, если он запрещает сон
системы или экрана по бездействию. `caffeinate -s` засчитывается только от
сети: от батареи macOS его не учитывает.

## Ограничения

Это ограничения macOS, а не приложения:

- Запрещается только сон **по бездействию**. Если закрыть крышку MacBook, он
  уснёт. Исключение — режим закрытой крышки: питание от сети плюс внешний
  монитор.
- Таймеры на время сна останавливаются, так же как `caffeinate -t`. Таймер на
  2 часа — это 2 часа бодрствования.
- Если строка меню заполнена, macOS прячет новые значки под вырезом экрана.
  Освободите место: перетащите значки с зажатой ⌘ или скройте лишние в
  Настройках → Строка меню. Если открыть приложение ещё раз через Spotlight или
  Finder, оно покажет окно с состоянием и кнопкой включения.

## Установка

Нужны macOS 15 или новее и Xcode Command Line Tools
(`xcode-select --install`).

```bash
git clone https://github.com/anton-vinogradov/caffeine-bar.git
cd caffeine-bar
./build.sh install
```

`build.sh` собирает `main.swift` через `swiftc`, подписывает приложение ad hoc,
копирует его в `~/Applications` и запускает. У локальной сборки нет флага
карантина, поэтому Gatekeeper её пропускает. Без `install` скрипт только
собирает `build/CaffeineBar.app`.

Чтобы приложение запускалось при входе, выберите в меню **Запускать при
входе**.

## Совет для скриптов и агентов

Передайте `caffeinate` pid процесса, который живёт столько же, сколько работа.
Тогда `caffeinate` завершится вместе с ней и не будет ждать весь `-t`:

```bash
caffeinate -dimsu -t 7200 -w $PPID &
```

`$PPID` — это процесс, который запустил текущую оболочку. У shell-инструмента
ИИ-агента это обычно сам агент.
